Un modèle de workflow que l'on peut décliner pour chaque client : on règle les sujets à surveiller, le reste tourne seul.

## Trois types de veille

- **Concurrentielle** : ce que font les autres acteurs du marché.
- **Réglementaire** : les évolutions de règles qui touchent le métier du client.
- **Sectorielle** : les actualités de son domaine.

## Points techniques

- Construit à partir de mon workflow « Actions », déjà éprouvé.
- Les alertes arrivent directement sur Telegram.
